# Book Cover

这个分支服务于单书封面，或书籍笔记后续要引用的封面图。

## 先收集什么

- 书名
- 作者、版本、已有笔记或气质要求（如果用户给了）

## Prompt 约束

- 默认走 `jimeng-image-prompt-crafter` 的封面语境。
- 如果用户只给书名，先做标题驱动、气质保守的封面 Prompt，不凭空编造书里的具体情节或场景。
- 默认优先竖版封面构图；如果用户明确给了比例或落点，再按用户要求覆盖。
- 标题要先立住，视觉元素只负责托住书的气质，不要把它做成泛宣传海报。

## 只有用户要求接回仓库时

- 书籍封面统一放 `assets/cover/`。
- 文件名默认直接用书名，不套“日期 + 英文短语”。
- 只有当图片已经放到 `assets/cover/` 且用户要求引用时，才把封面写回书籍笔记。
