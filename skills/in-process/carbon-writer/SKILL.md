# carbon-writer

为本仓库的课程、学习反思、读书导读、技术观察等非虚构场景起草或重写稿件。
目标是写出具体、克制、像一个真实作者写的成品。
这条候选 skill 通过 [`idea-to-skill`](../../stable/idea-to-skill/SKILL.md) 进入 `skills/in-process/`，先用短入口试跑，再决定是否稳定化。

## Before you start

- 先读 [`./reference/nonfiction-checklist.md`](./reference/nonfiction-checklist.md)。
- 先确认场景真的属于本仓库的非虚构写作；具体适用范围与排除项都以 checklist 为准，不在主文件里重复展开。
- 先锁定入口模式：`from-scratch`（从材料起稿）或 `rewrite`（重写现有草稿）。

## Steps

1. 压实这次写作的最小输入。
   完成标准：至少已经拿到主题、目标读者、这篇为什么现在要写、这篇要成立的判断、现有材料或旧稿之一；如果还要写长稿，再补够最少的真实材料。输入太薄时，只追问 1-3 个缺口，或者把产出缩到更小。
2. 按入口模式搭骨架。
   完成标准：`from-scratch` 已经决定“先列提纲”还是“直接起短稿”；`rewrite` 已经判断问题是词句层还是结构层，并且明确允许替换弱标题、重排段落顺序、重写 framing。
3. 写出新稿，不替材料和判断胡编。
   完成标准：段落里已经能看到具体事实、场景、对比或作者判断；空泛解释、假细节、套模板推进被删掉；需要重写时，以更好的标题和结构为准，不被原稿绑住。
4. 用清单收尾并再改一轮。
   完成标准：已经按 [`./reference/nonfiction-checklist.md`](./reference/nonfiction-checklist.md) 过完材料检查、坏味道扫描和“像真人写的”终审；没过的地方已经继续改，不把问题留在说明里。

## Finish

- 确认成品保住了作者自己的判断和语气，而不是被磨成平衡但空的说明文。
- 确认材料不够时没有硬撑长稿；要么补材料，要么明确缩 scope。
- 确认标题、开头和段落推进都服务这篇文章本身，而不是沿用原稿里更弱的说法。
