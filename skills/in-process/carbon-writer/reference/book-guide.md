# 导读分支

这条分支只处理书籍导读、资源解读、伴读型长文。它们不是抽象书评，也不是替读者读完全文的总结。

## 先压实四件事

- 这本书或这份材料在处理什么问题。
- 今天最容易把它读偏成什么。
- 为什么它对当前读者还值得读。
- 第一次读应该抓哪几根线。

这四件事没压实之前，不要直接开写。

## 写作目标

- 带读者进入材料，而不是替作者发言。
- 帮读者判断哪些部分值得重点看，哪些部分只要知道存在即可。
- 如果材料比较老，帮读者分清“今天仍有用的思想”和“带时代局限的实现细节”。

## 常见跑偏

- 把导读写成一篇只剩判断腔的书评。
- 还没拿到够多的章节线索或摘录，就抢着总结作者“真正想说什么”。
- 为了显得有洞察，连续写“这本书最厉害的地方是”“作者真正解决的是”这类大句子，却不给材料支撑。

## 更好的写法

- 多写“你读的时候可以盯住什么”“哪些地方今天最容易被用歪”。
- 多写“先抓这条主线，再看后面的展开”，少写“这本书伟大在于”。
- 需要按章导读时，把它写成决策辅助，不写成章章摘要。

## 按章导读

只有在章节差异真的会影响阅读路径时，才加 `按章导读`。

默认写成决策表，至少覆盖：

- 章节或部分
- 建议：优先读 / 选读 / 速读 / 可暂跳
- 原因
- 与今天的关系

如果一本书整体都还值得通读，就不要为了“完整”硬加按章表。
