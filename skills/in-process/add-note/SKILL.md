# add-note

把一条摘录或启发按“一文件一卡”的方式写进 `摘录与启发/`，正文默认原样保留，并同步更新目录索引。

## Before you start

- 这条 skill 只用于把内容收进 `摘录与启发/`；如果目标已经长成成型方法解释，就不要用它，改放 `AI编程方法论/`。
- 先压实这次输入：卡片标题、正文原文，以及索引里的一句话注释。
- 如果标题缺失，只追问标题；如果索引一句话注释缺失，就基于正文补一条简短注释，但不要改正文内容。
- 如果用户明确要求原样贴内容，正文必须逐字保留，不补导航、不补过渡语、不重写。

## Steps

1. 锁定卡片文件名和索引条目。
   完成标准：已经确定卡片标题、目标文件名和 `摘录与启发/README.md` 里的索引一句话注释；如果同名文件已存在，也已经先向用户确认是覆盖还是改名。
2. 写入卡片正文。
   完成标准：卡片文件落在 `摘录与启发/<标题>.md`；文件默认只有标题和正文，不额外补“返回索引”、说明文字或 AI 改写。
3. 更新 `摘录与启发/README.md` 索引。
   完成标准：README 里已经有这条卡片的本地链接，且索引条目满足“名称 + 一句话注释”的最小字段要求。
4. 收尾检查。
   完成标准：正文与用户提供内容一致；本地链接都指向现有文件；没有顺手创建多余目录、备注或临时草稿。

## Finish

- 确认这条卡片仍然是“轻量沉淀”，没有被扩写成方法论文。
- 确认正文如果来自用户贴文，就保持原文，不把我的解释混进去。
- 确认如果这条内容以后长成成型解释，再迁到 `AI编程方法论/`，而不是现在就写重。
