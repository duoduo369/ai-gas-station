# readme-course-cover

## 来源

- 模式：`migrate-playbook`
- 源材料：历史条目 `playbook/课程封面：给 README 做可点击入口.md`（已在迁移完成后删除）

## 这条 skill 解决什么

- 给知识库里的课程生成同系列、可点击、能说明课程对象与主流程的 README 封面 Prompt。
- 约束“先理解课程，再做封面，再把入口接回 README”的最小闭环。

## 这条 skill 不解决什么

- 不替代真正的出图工具；它只负责把图像需求压成可执行 Prompt。
- 不在课程标题和定位还没稳定时强行出图。
- 不负责课程内容本身的写作或 lesson 结构设计。

## 迁移备注

- 旧 playbook 里关于“标题系统先抓眼球、主体细节随后锁方向”的判断，已经压缩进主 `SKILL.md`。
- 长解释、系列语言和 Prompt 骨架保留在这里，供后续继续收口时参考。
- 迁移完成后，封面方法进入候选 skill 生命周期，不再保留旧 playbook 文档。

## 系列约束

- README 课程封面默认是信息型封面，不是泛 AI 海报。
- 主标题优先使用最有辨识度的课程名或对象名，课程类型词只做解释。
- 系列默认维持 `4:3`、稳定标题安全区和偏课程册 / 信息设计的气质。
