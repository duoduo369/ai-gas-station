# Course Cover

这个分支服务于课程 README / `课程/README.md` 的入口封面。

## 先收集什么

- 课程名
- 课程 `README.md`
- `MISSION.md`（如果有）
- 1-2 个能代表视觉语言的现有资产

## Brief 要压出的四件事

- 学习对象
- 主流程
- 画面骨架
- 不要什么

## Prompt 约束

- 默认走 `jimeng-image-prompt-crafter` 的 `cover` 语境。
- README 课程封面默认是信息型封面，不是泛 AI 海报。
- 主标题优先使用最有辨识度的课程名或对象名，课程类型词只做解释。
- 主体必须能对上课程的学习对象和主流程；如果标题稳了但主体总跑偏，就继续补主体细节，不要只靠气氛词。
- 比例默认 `4:3`；如果用户明确给了别的落点或比例，再按用户要求覆盖。

## 只有用户要求接回仓库时

- 课程入口图通常走 `assets/image/`。
- README 入口同时保留封面点击和普通文本链接，不只靠图片承载入口。
