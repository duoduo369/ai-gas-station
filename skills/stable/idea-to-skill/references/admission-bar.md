# What Qualifies

只有满足下面这些条件的方法，才值得送进本仓库的 project-level skills lifecycle：

- 已经清楚地预期下次还会再用，而不是这次任务的临时说明。
- 触发时机已经说得清，不需要靠大段背景才能理解何时该用它。
- 核心动作能压成短步骤，并写出可判断的 completion criteria。
- 运行时还需要的规则，能够收口到 skill 自己的 `SKILL.md` 或同目录 `references/`，而不是每次再跳回外部文档。
- 它服务的是当前工作区的协作，不是某个用户跨项目的个人习惯。

如果一个方法还不满足这些条件，就停在当前上下文文档，不要急着抬升成 skill。
