# stable

这里放已经在本仓库里站稳的 project-level skills。
它们可以被当作标准入口推荐给协作者使用，默认仍然是 user-invoked。
如果某个候选 skill 已经过真实验证，并且准备从 `in-process` 提升到这里，先调用 [`release-skill`](../in-process/release-skill/SKILL.md) 走 release 流程。
