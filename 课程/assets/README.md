# 课程共用 chrome

各课 `lessons/`、`reference/` 共用的样式和外链脚本。

- `course.css`：课件版式、导航、测验、嵌入块、示意图
- `open-links-new-tab.js`：把页面里的 http(s) 链接开到新标签

lesson / reference 里写成 `../../assets/course.css` 和 `../../assets/open-links-new-tab.js`。

课表导航、测验脚本、该课自己的图仍放在各课自己的 `assets/`。写课覆盖层见 [playbook/teach-me.md](../../playbook/teach-me.md)。
