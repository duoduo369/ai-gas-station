启动时实际读什么

Codex 吃的是生成文件 .swarmforge/prompts/<role>.md：先递归读宪法文章，再读角色 prompt。two-pack 文章是 workflow / handoffs / engineering（main）+ project（pack）。全文中文在 0002 按调用顺序展开。

  1. New Task → coder（名字即全程 task:）
  2. coder TDD → git_handoff to: cleaner priority: 50（可能先 AUDIT_REQUIRED）
  3. cleaner 一批清理/架构/变异 → to: coder priority: 00＝末棒，卡片 Done
  4. coder merge + 单测 + done_with_current.sh，不再转发

禁区

Gherkin、IR、验收测试、Gherkin 变异、属性测试。来源：project.prompt。
