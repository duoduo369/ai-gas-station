four-pack 流程速查

回看用的压缩版：忘了谁是 master、人闸卡在哪一跳、卡片何时进 Done 时先翻这一页。对应课件：Lesson 0003。对照 two-pack。

合成

get-swarm-forge four-pack … = main 的 scripts + 三篇共享宪法 + pack 的 conf / roles / project.prompt / local-workflow.prompt。four-pack 的 swarmforge/ 本身没有 scripts。

拓扑

conf：specifier@master task · coder task · refactorer task · architect batch。全是 codex + yolo。New Task / 聊天只找 specifier。

启动时实际读什么

Codex 吃的是生成文件 .swarmforge/prompts/<role>.md：先递归读宪法文章，再读角色 prompt。four-pack 文章是 workflow / handoffs / engineering（main）+ project 与 local-workflow（pack）。全文中文在 0003 按调用顺序展开。

一轮

  1. New Task → specifier 五阶段写 Gherkin → to: coder（停在 Attention）
  2. 人 Approve → coder（验收管线 + TDD）→ to: refactorer
  3. refactorer：清理、CRAP/DRY、数变异位点 → to: architect
  4. architect：结构 + 真变异 + 软 Gherkin 变异 → 有功能则 to: 其余三人 priority: 00＝末棒，卡片 Done
  5. 收到 architect 的人只 merge 验证（specifier 问下一张卡），不转发
