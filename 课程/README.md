# 课程

多课时、可以独立回看的课程包。点封面或标题会打开该课第一份 HTML；也可以进对应课程的 `lessons/` 目录，按编号直接打开课件学习。建议用 Obsidian，打开“文件与连接”里的“检测所有类型文件”，直接在课程目录里找到各课 `lessons/` 下的 HTML。课程目前主要用 [teach-me](https://github.com/duoduo369/teach-me) 这个 skill 生成。
