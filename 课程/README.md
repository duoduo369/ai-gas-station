# 课程

这里收多课时、可独立回看的课程包。
每门课都放在自己的子目录里，带上 `README.md`、`lessons/`、`reference/`、`assets/`，整门课可以一起移动、回看、续写。
共用课件样式和外链脚本在 [`assets/`](./assets/README.md)；各课自己的 `assets/` 只放课表导航、测验脚本和该课的图。写课覆盖层见 [playbook/teach-me.md](../playbook/teach-me.md)。
