# Mission: 读懂 mattpocock/skills 并迁到自己的工作流

## Why

你已经在用 agent skills，现在要把 `mattpocock/skills` 从“仓库里有一堆 SKILL.md”读成“可组合的流程系统”。学完后，你能按自己手头的任务选对入口（grill / wayfinder / triage / implement / code-review），并把 tracker、handoff、验收这些纪律迁到日常，而不是把整仓 skill 背下来。

## Success looks like

- 能画出仓库地图：五个 bucket、promoted 与否、user-invoked / model-invoked，以及 `ask-matt` 的主线位置。
- 能沿主线判断下一步：`grill-with-docs` → `to-spec` → `to-tickets` → `implement`，以及何时走上坡入口。
- 能分清 `grilling`、`grill-with-docs`、`wayfinder` 的边界，以及 `/handoff` 是产物不是终止器。
- 能做整分支验收：两轴 `code-review`、spec 是快照、本地 `.scratch` 不必再 triage。
- 能把 issue tracker 看成配置：改 `docs/agents/issue-tracker.md`，不改 `SKILL.md`。

## Constraints

- 课程包放在本知识库 `课程/mattpocock-skills 仓库学习课/`；课件用 HTML，源码引用走 GitHub，保证换机器仍能打开。
- 本地克隆在 `D:\work\codeup\mattpocock-skills`，允许备课对照；课件里不写本地绝对路径。
- `skills/` 下已有 grilling、handoff、wait-what、writing-for-agents 等拆解，以及仓库地图笔记；课要加厚权威中文，而不是另起一套摘要。
- 先地图，再沿主线精读；不要求一次课覆盖全部 skill。

## Out of scope

- 现在不把这套 skills 接到本知识库的 playbook，也不改 fork。
- 不把每个 skill 都做成逐字翻译课；只嵌本课要学员对照着做的权威正文。
- 不单独做飞书 Base 接线草稿，除非用户明确要下一课写。
