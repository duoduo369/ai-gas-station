先记住这一句

teach 管“这门课为什么学、怎么续”；teach-me 管“这门课在这个仓库里长成什么样”。

teach-me SKILL.md 把工作区、资料、lesson、reference、learning-record 继续沿用上游 teach。它再额外规定三件事：正文要写成中文 HTML，写前先读写作和 HTML 指南，多课时要维护 course-nav.js。

这张卡多管了哪些事

层 上游 teach teach-me 在本库加的约束
工作区 当前目录就是教学工作区，连续性落在文件里 课程工作区通常落在 课程/某课/，lesson、reference、assets 都在这门课里收口
文章 lesson 是主产物，一课一事 lesson 必须是中文 HTML，头部挂本课 course.css、open-links-new-tab.js、course-nav.js
写法 知识围着技能来，判断挂在使命上 写前先读 中文写作指南，正文去翻译腔、去 AI 味、每段推进一步
配图 上游没把图的开关单列出来 先问用户要不要配图。默认不加，只有关系靠文字不容易一眼看懂时才加
导航 工作区能续课，连续性主要靠文件 课数大于 1 时，必须维护 course-nav.js，补顶部导航和底部上一课 / 下一课

所以这门课把 teach-me 放在第一课。你现在看到的课程外观、目录落点和导航顺序，都是它先定的；第二课再回去讲上游 /teach 的工作区哲学和调用时机。

工作流现在是五步

1

先把使命钉住

MISSION.md 空着，就先追问为什么学。使命模糊，比没有使命更糟。这条在 teach-me SKILL.md 里写得很硬。

2

先填 RESOURCES，再出课

至少 2 到 3 条高信任资料。每条写清覆盖什么、什么时候用。资料不够，就停在 RESOURCES.md，不要用模型记忆硬讲。

3

先问要不要配图

默认不加图。你点头了，再只给那些文字一眼讲不清关系的地方加图。这个开关是 teach-me 比上游 teach 更具体的一层。

4

写成能直接打开的 HTML

写之前读 中文写作指南 和 HTML 指南。hero、section、表格、卡片、提示框都有固定写法。

5

压出速查，再维护导航

值得回看的内容压进 reference/。课数变成两篇以上，就更新 course-nav.js，让 lesson 和 reference 能前后串起来。

教学工作区

当前目录就是教学工作区。学习状态落在这些文件里：

  • MISSION.md：为什么学这个。所有教学决策都从这里出发。
  • RESOURCES.md：高信任资料清单。课里的判断从这里引，不用参数化知识胡编。
  • ./lessons/*.html：学习文章。一篇讲清一件事，是教学工作区的主产物。
  • ./reference/*.html：速查页。从文章里压出来的精华。以后回看走这里。
  • ./learning-records/*.md：学习记录。记录非显然的学会的东西，用来算下一篇文章该写什么。
  • ./assets/*：该课程的可复用组件。导航脚本放这里。
  • NOTES.md：草稿。记录用户偏好、工作笔记。

工作流

  1. 先确认 MISSION.md。使命空着时先追问为什么学。
  2. 先确认 RESOURCES.md。至少要有 2 到 3 条高信任资料，缺口写进 Gaps。
  3. 先问要不要配图。默认不加图。
  4. 写文章前先读 chinese-writing-guide.md 和 html-guide.md。
  5. 写完后按需压 reference，课程大于一篇时再维护导航。

三份 guide 把“课长什么样”说死

原文：写作指南、HTML 指南、导航指南。

展开本课要用的规则 收起本课要用的规则

中文写作指南

  • 像个懂行的人在跟朋友解释一件事。
  • 每段都带来新东西。删掉这一段，读者就该少知道一点东西。
  • 教学文本先说结论，再展开。不要铺垫三段才到重点。

HTML 指南

  • hero 只放 eyebrow、h1、lede。
  • 正文每节一个 h2 起头。
  • 表格放在 div.table-wrap 里。
  • 权威正文嵌入 lesson 时，用静态 HTML 块，不把 Markdown 源码直接摊给读者看。

导航指南

  • course-nav.js 必须是完整可执行脚本，不只是数据。
  • 顶部要有课程导航。
  • lesson 页底部要有上一课 / 下一课。
  • 当前页高亮用 aria-current="page"。

你在这个仓库里该怎么开口

这张卡最适合拿来写本库的课程包。课程目录、课内样式、导航脚本、reference 入口都已经是它要的形状。你开口时，把主题、目录落点和写作约束一次说完，后面返工最少。
