teach-me 覆盖层速查

先回看这一页。分清它给上游 teach 多加了什么：中文写法、HTML 结构、配图开关、导航维护和课程目录落点。

先抓四个结论

  • teach 管教学工作区为什么学、怎么续。teach-me 管这门课在本库里怎样落成中文 HTML。
  • MISSION.md 和 RESOURCES.md 先于 lesson。资料不够，就停。
  • 配图默认关。只有文字一眼讲不清关系时才开。
  • 课数大于 1 时，assets/course-nav.js 必须跟着维护。

teach 和 teach-me 怎么分工

问题 看哪张卡
为什么学、成功标准、下一课该接什么 teach
课程目录放哪、lesson 和 reference 怎么命名 teach-me
正文该怎么写得像人、怎么去 AI 味 teach-me 的写作指南
多课时导航怎么做 teach-me 的导航指南
什么时候该打 /teach，什么时候直接问 teach 的人读 docs

teach-me 的五步工作流

步骤 动作 卡住时怎么办
1 确认 MISSION.md 理由模糊就继续追问，不先写课
2 确认 RESOURCES.md 至少 2 到 3 条高信任资料；不够就写 Gaps
3 问配图 用户没说，就按默认不加图
4 写 lesson HTML 先读中文写作指南和 HTML 指南
5 压 reference，更新导航 课数变多或顺序变化时，一起改 course-nav.js

你要盯住的文件

路径 作用
lessons/0001-*.html 主产物。一课一事。桌面和手机都能直接打开读。
