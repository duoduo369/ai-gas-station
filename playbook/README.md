# playbook

这里放已经验证过、后面还能直接复用的方法、流程、套路和准则。
它不是资料收藏夹，也不是临时灵感区，只有在“重复有效、值得再用”时才进入这里。
如果某个方法还在探索期，更适合先记录在 `skills/` 或对应对象目录，等稳定后再进入 playbook。

## 收什么

- 稳定有效的 AI 协作流程
- 反复验证过的提示词套路
- 值得长期保留的知识管理与整理方法
