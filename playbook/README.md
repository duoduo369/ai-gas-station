# playbook

这里放已经验证过、后面还能直接复用的方法、流程、套路和准则。
它不是资料收藏夹，也不是临时灵感区，只有在“重复有效、值得再用”时才进入这里。
如果某个方法还在探索期，更适合先记录在 `skills/` 或对应对象目录，等稳定后再进入 playbook。

## 收什么

- 稳定有效的 AI 协作流程
- 反复验证过的提示词套路
- 值得长期保留的知识管理与整理方法

## 条目

- [teach 课件：嵌入权威中文](./teach-课件-嵌入权威中文.md) - 课里点名的 prompt/skill 把中文嵌进 HTML，少让学员再翻上游；章节结构随课，不绑死流程拍序。
- [teach 课件：统一导航条](./teach-课件-统一导航条.md) - 多节课 / 多张速查页的课程别在每页手写导航，改成 `assets/course-nav.js` 统一注入，后续只维护一处列表。

## 现在先不收什么

- 一次性的灵感
- 还没验证的零散建议
- 只是链接收藏、没有自己判断的内容
