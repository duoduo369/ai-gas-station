# 摘录与启发

这里收录值得长期保留的一条摘录、一段评论，或被外部内容触发后留下来的轻启发。
它承接的是“一文件一卡”的轻量沉淀：可以只是纯摘录，也可以带一点改写或一句自己的判断，但不要求系统展开；来源链接也是可选的。
如果一条内容后来长成了能独立解释清楚的方法、机制或边界的文档，就应转入 [`../AI编程方法论/README.md`](../AI编程方法论/README.md)。
