# 书籍

这里收录值得长期保留的书籍入口，以及已经单开的书籍笔记。
不追求把所有看过的书都搬进来，只收“值得留、后面还会回看”的内容。
可以先只记索引条目。书籍笔记不要自动建，只有明确要求创建某书的 md 时才建；建出来会带三区：书目信息、个人阅读记录（人写，AI 不改）、导读（一篇程序员视角伴读）。封面后补到 `assets/cover/`，再让 AI 引用。写法见 [记录与协作规范](../docs/conventions.md)。

## 软件工程与项目管理

- 《人月神话》 - Frederick P. Brooks Jr.：人月不可互换、概念完整性、没有银弹；今天做团队、远程和 AI 协作时仍然成立。[阅读笔记](./人月神话.md)
- 《软件设计的哲学》（第 2 版） - John Ousterhout：软件难在管理复杂度；深模块、信息隐藏，以及把重要的事和不重要的事分开。[阅读笔记](./软件设计的哲学.md)
